LAST_INSERT_ID()  -- MySQL
SCOPE_IDENTITY()  -- SQL Server / SSMS

What SCOPE_IDENTITY() actually does
It returns the ID generated by the most recent INSERT in the current session. That is all it does. It has no memory of older inserts.
So if you insert a new user and immediately call SCOPE_IDENTITY(), it gives you that new user's ID. But if you want the ID of user 25 who was inserted earlier, SCOPE_IDENTITY() is useless there.

INSERT INTO users(name, email, gender, date_of_birth, salary)
VALUES ('Uj', 'uj@gmail.com', 'Male', '2001-07-05', 54000);

-- Right after, insert address for the user just created above
INSERT INTO addresses(user_id, street, city, state, pincode)
VALUES (SCOPE_IDENTITY(), 'Vishwas Nagar', 'Delhi', 'Delhi', '110032');
