# Data Stack Workbench

A collection of hands-on practice, drills, and mini-projects across the data and backend stack — built while learning and preparing for data engineering and backend development roles.

## Contents

- **Python/** — Practice drills organized by difficulty and topic
  - `Topics/` — Concept-wise exercises (type casting, slicing, control flow, functions, closures, recursion, exception handling, and more)
  - `Easy_Problems/` — Beginner-level problem solving
  - `Medium_Problems/` — Intermediate-level problem solving
  - `Hard_Problems/` — Advanced problem solving

- **SQL/** — Query practice, schema design, and reference notes (MySQL and SQL Server)
  - Table creation, joins, subqueries, window functions, stored procedures, transactions, set operations and more
  - `SQL_Query_Practice/` — Additional query drills

- **Azure/** — Azure Fundamentals notes and hands-on exercises 

- **PySpark/** — Practice with distributed data processing

- **CSharp/** — ASP.NET practice and exercises

- **FastAPI/** — Backend API practice

## Purpose

This repo consolidates practice material from separate private repositories into one place, showing consistent, ongoing hands-on learning across the tools and languages used in data engineering and backend development.

## Note

Some folders were originally maintained as separate branches or repositories during active learning; they've been merged here for a single, browsable view of the work.
